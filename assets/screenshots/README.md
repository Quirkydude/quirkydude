# Screenshots

Drop your images here using these exact names:

```
screenshot1.png
screenshot2.png
screenshot3.png
screenshot4.png
screenshot5.png
screenshot6.png
```

The profile README shows them in a 3 × 2 grid, in that order.

**Tips**
- Keep them the same shape: all landscape (around 1280×800) **or** all phone screens (around 1080×1920). Mixed sizes make the grid look uneven.
- Fewer than 6? Delete the unused `<td>` cells in the main README, or you'll get broken-image icons.
- Want a GIF? Save it as `screenshot1.gif` and change `.png` to `.gif` for that cell in the main README.
- Captions: replace the `<!-- caption N -->` comment inside each `<sub>` in the main README.
- Keep each file under ~5 MB so the profile loads fast.
